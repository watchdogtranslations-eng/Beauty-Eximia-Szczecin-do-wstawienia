# Eximia Beauty — wersja do GitHub Pages

Struktura projektu:

- `index.html` — strona główna
- `assets/css/style.css` — style strony
- `assets/js/script.js` — skrypty strony, jeśli występują
- `assets/images/` — wszystkie obrazy używane na stronie
- `.nojekyll` — poprawna publikacja statycznych plików przez GitHub Pages

## Publikacja przez GitHub Desktop

1. Rozpakuj ZIP.
2. Otwórz GitHub Desktop.
3. Wybierz `File → Add local repository`.
4. Wskaż folder `eximia-github-ready`.
5. Jeśli program zaproponuje utworzenie repozytorium, zaakceptuj.
6. Wykonaj commit i kliknij `Publish repository`.
7. Na GitHubie otwórz `Settings → Pages`.
8. Ustaw `Deploy from a branch`, gałąź `main`, folder `/ (root)`.
